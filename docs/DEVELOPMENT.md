# Local development & preview

Everything runs in Docker. Only Docker (with Compose v2) and Git are needed on your machine.

## First start

```bash
git clone https://github.com/dipelaserasmus-del/electronic_protocol.git
cd electronic_protocol
./dev.sh up
```

`./dev.sh up` builds the image, starts the containers, installs PHP dependencies, creates the
database with demo data and loads the mock mailbox. Then open:

| What | Where |
|------|-------|
| Application | http://localhost:8080 — users `admin`, `anathetis`, `writer`, `reader`, password `password` |
| Outgoing mail (receipts, notifications) | http://localhost:8025 (Mailpit — nothing is really sent) |
| MySQL (for a DB client) | `localhost:33060`, user `laravel` / `astrongpass`, database `laravel` |
| Mock IMAP mailbox | `protocol@school.test` / `secret` (inside Docker: `imap:3143`) |

Your normal `.env` is never used or changed by the dev stack: it reads `.env.development`
(created automatically from `.env.development.example`).

## Everyday commands

| Command | Does |
|---------|------|
| `./dev.sh up` | start (or update after `git pull`) |
| `./dev.sh down` | stop |
| `./dev.sh test` | run the automated tests (separate `testing` database) |
| `./dev.sh mail` | regenerate test emails and reload the mock mailbox |
| `./dev.sh reset` | wipe the dev database and recreate demo data |
| `./dev.sh artisan <cmd>` | run a Laravel artisan command |
| `./dev.sh shell` | shell inside the app container |
| `./dev.sh logs` | follow the logs |

To preview a task branch: `git fetch && git checkout task/<ID>-... && ./dev.sh up`.

## Test emails

- `tests/fixtures/emails/synthetic/` — invented emails covering the hard cases (Greek legacy
  charsets ISO-8859-7 / Windows-1253, Outlook-style attachment names, forwarded messages,
  special characters, long subjects, raw 8-bit headers). Generated by `docker/dev/make-emails.php`.
- `tests/fixtures/emails/real/` — real emails you approved as safe to publish (the repository is public).
- `local-data/emails/` — **your private emails**. This folder is git-ignored: the files stay on your
  machine, are loaded into the mock mailbox by `./dev.sh mail`, and are never committed or uploaded.

## Your real data

Real data stays on your machine only, in the git-ignored `local-data/` folder. A separate local copy
(http://localhost:8081) loads a production backup with `./dev.sh real load`: see
[LOCAL-REAL-DATA.md](LOCAL-REAL-DATA.md).

## Why Ubuntu-based image

The app image is Ubuntu 26.04 LTS with the distribution's PHP 8.5 (security updates until 2031).
`ext-imap` is deliberately not installed: it was removed from PHP 8.4 core and relies on the
unmaintained c-client library. Email is read with `webklex/php-imap` over native sockets, with a
custom header decoder (`app/Support/Imap/HeaderDecoder.php`) for Greek charsets.
