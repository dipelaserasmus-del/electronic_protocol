## What was found
- Every page after sign-in already uses the new layout (R1–R7); the old layout serves only the 4 sign-in pages.
- Nothing loaded jQuery **1.9.1** (`public/js/jquery.min.js`, only in an HTML comment), `npm.js` or the Bootstrap 4
  `public/css/app.css`; the old Vue / jQuery / Sass sources were built by nothing; 26 of the 28 icons were shown nowhere.
- Two routes with no caller: `/updated` (a link of the old layout that could no longer appear) and
  `getKeep4Fakelos`; methods never called; view variables nothing reads.

## What changed (removed)
- `public/js/jquery.min.js`, `public/js/npm.js`, `public/css/app.css`; 26 icons in `public/images` (kept: `books.jpg`
  for the welcome page, `email.png` for *Σχετικά*).
- `resources/js`, `resources/assets`, `resources/sass` (the Vue 1 / jQuery / Bootstrap-Sass sources of the old build).
- `resources/views/vendor/pagination/*` and `Paginator::useBootstrap()` (no page draws Laravel's pagination links: the
  lists use their own pager).
- Routes `GET /updated`, `GET getKeep4Fakelos/{fakelos}` and their methods; `ProtocolController::filter_filename()` /
  `beautify_filename()` (replaced by `FileNames` in F08); 16 imports of `ProtocolController` nothing used.
- The view variables `myUsers` and `titleColorStyle` and `User::my_users()`.
- The old layout's update link and its commented-out script tags; the e2e `toasts()` helper (it read toastr's
  messages; the new pages have their own).
- `docs/reports/VERSIONS.md`: jQuery 1.9.1 noted as removed.

Nothing anyone sees changes.
