## What runs on every pull request and every push to `master`

| Job | What it checks |
|---|---|
| Tests (PHP 8.4, MySQL 8.4) | full PHPUnit suite on a real MySQL 8.4 server |
| Tests (PHP 8.5, MySQL 8.4) | same on PHP 8.5 (the version in the Docker image) |
| Dependency security audit | `composer audit` — **fails** on any known vulnerability in PHP packages; `npm audit` report-only until the frontend is modernized (N03) |
| Docker image builds | builds the app image from scratch and checks PHP, extensions and PHP-FPM config |

Test results (JUnit XML) are kept as artifacts of each run.
Rule from now on: a task's PR is merged only when all four jobs are green.
