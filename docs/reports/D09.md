## What was wrong
The preview of `folders:glossary` on the owner's real copy (try-it 38, 2026-11-23) listed three folders of the copy as
*not in the glossary*. Their codes differ from the list by more than the dot after Φ, so D08 treats them as other
folders, and `--apply` would have added the list's folder as a **second** one:

| On the copy | In the list |
|---|---|
| `Φ32.β` | `Φ.32β` *Περιφερειακή Επόπτρια Κρήτης Συμβούλων Εκπαίδευσης* |
| `Φ29Α` | `Φ.29` *ΚΑΤΑΣΚΗΝΩΣΕΙΣ…* |
| `Φ33.β` | `Φ.33.1` *Εγκύκλιοι και νομοθεσία μόνιμου διοικητικού προσωπικού* |

## The owner's decision (2026-11-23)
- `Φ32.β` is the same folder as `Φ.32β`.
- `Φ29Α` is the same folder as `Φ.29`.
- `Φ33.β` is the sub-folder of `Φ33` that the list calls `Φ.33.1` (other wording).

## What changed
- **Glossary** (`database/data/folders.json`): `Φ.29`, `Φ.32β` and `Φ.33.1` have `aliases` (the code on the copy) and an
  `aliasNote` with the decision. [docs/FOLDERS.md](../FOLDERS.md) has a new section *Ίδιος φάκελος, άλλος κωδικός*
  listing them.
- **`FolderGlossary::records`**: when the copy has no folder with the list's code, a folder with one of its aliases is
  updated instead. It gets the list's description and **keeps its own code**, with retention and remarks unchanged, so
  no second folder is added. The list's own code still wins when both exist.
- **Preview wording:** *«Φ.32β is your Φ32.β: the same folder (it keeps its code, no second one is added).»* The old
  *«… that folder is updated»* was also printed for folders whose description was already right (`Φ.4.3`, `Φ.44`).
- The `about` text in the JSON named an old command (`fakeloi:sync`). It now says `folders:glossary`.

## Verification
- `test_an_alias_updates_the_existing_folder_and_keeps_its_code`: a copy with `Φ29Α`, `Φ32.β` and `Φ33.β`. The preview
  names all three as the same folder. After `--apply` there is no `Φ.29`, `Φ.32β` or `Φ.33.1`, and the three keep their
  codes, retention and remarks, with the list's descriptions.
- `test_the_code_itself_wins_over_an_alias`: with both `Φ.33.1` and `Φ33.β`, only `Φ.33.1` is updated.
- `test_the_glossary_is_well_formed`: the three aliases as decided, and no alias is another folder's code.
- Full PHPUnit suite. Command-line only, no screen changes, so no browser test.
