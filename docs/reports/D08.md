## Your note (2026-11-20)
The old app wrote some folders as `Φ.2` and some as `Φ12`. The dot is only there for readability, and it should not
count when searching or when choosing a folder.

## What was already right
R1h made the *folder picker* and the comparison of a typed code with the folder list ignore the dot. Only the dots
inside the number count: `Φ.1.1` is not `Φ.11`.

## What was missing, now fixed
| Where | Before | Now |
|---|---|---|
| Search: folder field, `φάκελος:` | only the codes **as the folder list writes them** | also every spelling the protocols use: list `Φ.812` finds protocols saved as `Φ812` and `φ 812` |
| Search: free words (`Φ812` typed in the box) | only text containing exactly that spelling | every spelling of that folder (a number alone is still a protocol number) |
| Merge Φ.43 → Φ.46 (D07) | only protocols saved exactly as `Φ.43` | `Φ43`, `Φ.43` … all move; the target is written as your list writes it; list rows `Φ43` and `Φ.43` are both merged |

Your protocols keep their code exactly as written; nothing is rewritten.
