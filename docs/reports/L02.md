## Answer: yes, use the RPM VS Code on Fedora
With the RPM, Fedora behaves like the Mac:
- the terminal and tasks see Docker directly;
- there is no `flatpak-spawn` layer and no permission override;
- the same settings work on both computers.

The Flatpak gave no real isolation here anyway: the permission it needs lets VS Code run any command on the
computer. The repository still works with the Flatpak.
